# Smart Solar Microgrid Trading System

This project was developed for the SE4040 – Enterprise Application Development module.

The Smart Solar Microgrid Trading System is a client-server application for managing solar microgrid stations, energy booking slots and reservations. The system includes a React web application, a native Android application and an ASP.NET Core Web API with MongoDB.

## Technologies Used

- React.js
- ASP.NET Core Web API
- C#
- MongoDB
- Kotlin
- SQLite
- Google Maps SDK
- JWT Authentication
- Git and GitHub
- Postman

## Applications

### Web Application
The web application is mainly used by Backoffice users and Grid Operators for managing users, stations, slots, reservations and system operations.

### Android Application
The Android application is used by Prosumers and Grid Operators. Prosumers can manage their profile, find nearby stations, make reservations and view booking details. Grid Operators can scan QR codes and complete energy transfers.
